# Building-and-Securing-Serverless-Applications-Using-AWS-Lambda
Serverless Application using AWS Lambda
Overview
This project demonstrates how to create a simple serverless application using AWS Lambda and API Gateway. The application returns a basic response through an HTTP endpoint.

Technologies Used
AWS Lambda
Amazon API Gateway
Python

Steps
Create a Lambda function in AWS
Write a simple Python function
Test the Lambda function
Create an API using API Gateway
Connect API Gateway to Lambda
Deploy and test the API

Output
When the API endpoint is accessed, it returns:
Hello from Secure Serverless App!

Conclusion
This project shows how to build and deploy a basic serverless application and test it using AWS services.
